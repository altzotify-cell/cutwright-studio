Recap Studio: step by step

A guide for every video type. Everything happens in the app (the browser tab that START_UI.bat opens). Bold tab names mean the tabs along the top of a project.

0. One-time setup

  1. Run SETUP.bat onceIt installs the Python packages, yt-dlp and FFmpeg. If something later says "missing", run it again.
  2. Double-click START_UI.batYour browser opens Recap Studio. Keep the black window open while you work; close it to stop the app.
  3. Check the tool lights (bottom-left)FFmpeg, ffprobe, yt-dlp and edge-tts should be green.
  4. Add API keys (optional): click 🔑 API keysPaste your ElevenLabs and/or MiniMax key and press Save. You can paste several keys separated by commas. You can skip this entirely and use Edge-TTS, which is free and needs no key.
  5. Pocket TTS voice cloning only: add a Hugging Face tokenSee Pocket TTS voice cloning setup below. Built-in Pocket voices and every other engine do not need it.
Keys are secrets. They are saved only in keys.env on your computer. Never send that file to anyone, and if you share the RecapStudio folder, delete or blank keys.env first.

1. How every video works

All six video types use the same pipeline. A video is a list of segments: one line of narration plus the picture that plays under it. Claude writes that list for you; the app turns it into voice and video.

PhaseWhat happensWhere
1. CreateMake a project and pick the video type, length and style.＋ New project
2. SourceRecaps: add the film. Others: collect clips and images.Footage
3. ScriptCopy the prompt, give it to Claude, paste Claude's reply back.Script
4. VoicePreview 3 segments, then generate the full voice-over.Voice
5. BuildMake the Premiere sequence (and the mp4 for recaps).Run steps
6. CollectOpen the finished files.Outputs
Two things to know. (1) ▶ Run all on the Run steps tab also generates the voice-over, which can spend ElevenLabs credits. Only press it once your script is imported and you've done a Preview. (2) Claude here means a separate chat (claude.ai). The app does not talk to Claude by itself; you copy and paste between them.

The Claude hand-off (same for every type)

  1. Script tab → Copy promptThe prompt already matches your video type.
  2. Open a new Claude chat and paste itThen tell Claude your topic or film, length and anything special. Recaps: also attach the .srt file (see below).
  3. Copy Claude's whole replyDon't trim it; the app finds the JSON inside by itself.
  4. Script tab → Paste Claude's reply → Import JSONYou'll see the segments as cards. Edit any text right there, then press 💾 Save script.

2. Movie recap

A narrated retelling of one film, cut from the film itself.

Default length 10:00Source: the film fileCan finish as a ready mp4
  1. ＋ New project → Movie recapName it after the film. Pick a style: retell (what happens), commentary (themes and analysis) or mixed. Set the target length.
  2. Put the film in the project folderFootage tab → "The film / episode (project root)" → Upload video. For big files (over ~2 GB) it's faster to click 📂 Open folder and drag the film into the folder. For a single film it must be in this main folder (not footage/), because the build looks for the one big film there.
  3. Run steps → Extract subtitlesSaves the film's subtitle tracks into the subs/ folder. Find the English .srt there (📂 Open folder).
    No subtitles found? Some films have none embedded, or only picture-based ones (which can't be converted). Download an English .srt for that exact version of the film and drop it into subs/.
  4. Get the script from ClaudeDo the hand-off above and attach the .srt. Claude cuts the film into segments, each with a time range anchored to the subtitle line it describes.
  5. Fix "need visual" parts (if any)Wordless or action scenes can't be read from subtitles, so Claude marks them need_visual. Run steps → Contact sheets, upload the images from sheets/ to the same Claude chat, and ask it to finalise. Import the new reply.
  6. Designed motion scenes (movie / show recap, optional)The movie prompt lets Claude add a short motion brief to the segments that deserve a custom graphic (a stat, a timeline, a comparison, a quote) and a theme for the whole film. After you import the script, open the Scenes tab → Copy scene prompt, paste it to Claude, then paste Claude's reply into the box and press Import scenes and check them. Scenes that pass are used in the Remotion render; a scene that fails is replaced by the animated-words fallback, and Copy fix prompt gives Claude the error to correct. Needs Build timeline.json first for the check.
  7. Voice tabPick an engine and voice, Save, then Preview 3 segments. Happy? Press Generate. Afterwards the log shows "target 10:00, actual 11:20…". If you're over, ask Claude to shorten the longest segments it lists, import, and Generate again. Only the changed segments are re-voiced.
  8. Run steps → Build full videoProduces recap_final.mp4. Each clip is cut to exactly the length of its narration. Want to polish in Premiere instead? Run Build Premiere XML.
  9. Captions (optional)Run steps → Build subtitles makes recap_subtitles.srt.
  10. TikTok version (optional)Ask Claude for a TikTok section ("add TikTok parts, hook first") and import it. Then Run steps → Build TikTok. Vertical 9:16 files land in tiktok_out/.
  11. Outputs tabPreview and download everything.
Heads-up: the mp4 doesn't burn in on-screen captions or number graphics. Those only appear in the Premiere XML version.

3. Show recap

Same as a movie recap, but across a whole season. Upload every episode at once; subtitles for all of them come out of one click.

Default length 10:00Source: episode filesCan finish as a ready mp4
  1. ＋ New project → Show recapName it after the show and season. Pick style and length as for a movie.
  2. Upload all the episodes at onceFootage tab → Episodes → Upload episodes (many at once), then select every episode in the file picker (Ctrl+A). They are saved in footage/. For a full season it's faster to click 📂 Open folder and drag all the files into the footage folder.
    Name them so they sort in order: Episode01.mkv, Episode02.mkv, … (or the show's own file names, as long as they're in story order).
  3. Run steps → Extract subtitles (once, for all episodes)It goes through every episode and saves the English subtitles into subs/. It also writes subs/ALL_EPISODES_for_claude.txt: every episode's subtitles in one file, each block headed with the episode's file name.
    An episode with no usable subtitles is listed in the log. Download an English .srt for it and put it in subs/ named like the video (Episode03.srt for Episode03.mkv), then run Extract subtitles again. It's picked up and added to the combined file.
  4. Get the script from ClaudeDo the hand-off and attach just ALL_EPISODES_for_claude.txt. Claude uses each block's episode file name as the segment's src. Episodes stay in story order unless you ask otherwise.
  5. Contact sheets, Voice, Build, TikTokExactly as steps 5–10 of the Movie recap. Everything finds the right episode from each segment's src, so there's nothing more to do per episode.
If a segment shows a black slate, its src name doesn't match a file in footage/. Fix the name in the Script tab and Save.

4. NBA mini-doc

A chaptered NBA documentary (hook, chapters, closing line), built from clips you collect. Finishes as a rough cut in Premiere.

Default length 8:00Source: clips you collectOutput: Premiere XML
  1. ＋ New project → NBA mini-docFill in the topic (for example "Kobe's 81-point game"). Set the length.
  2. Get the scriptDo the hand-off. Tell Claude the topic. It replies with a fact-check table (every number, date and quote with a confidence flag) and then the JSON. Read the table and verify anything marked medium or low before you publish. Import the JSON.
  3. Footage tab → collect missing shotsEvery segment that needs footage appears as a card with a description, search links (YouTube / X / Google Images) and a fallback idea. For each card do one of:
    • Paste a link (optionally the time range like 1:42-1:51) and press Download. Only that part is downloaded, using yt-dlp.
    • 📎 Attach file if you already have the clip or downloaded it by hand.
    • Skip to leave a black "slate" card as a placeholder.
    Clips are saved as footage/<segment id>.mp4. Source links are logged in credits.txt.
  4. Run steps → Index footage (optional)For long full-video downloads, this makes contact sheets so Claude can give you exact timestamps, which you can then use as the range when you paste the link.
  5. Voice tabPreview 3 segments, then Generate. Check the "actual vs target" length in the log.
  6. Run steps → Build Premiere XMLCreates premiere_sequence.xml plus the shot list and chapters. Then Build subtitles. See Opening it in Premiere.
Tip: segments with crowd noise or commentary can have keep_audio set, so the clip's original sound plays quietly under your voice-over.

5. NBA story

A short, fast NBA piece (30–90 seconds): hook in the first 5 seconds, setup, turn, payoff. No chapters.

Default length 3:00 (aim for 0:30–1:30)Source: clips you collectOutput: Premiere XML
  1. ＋ New project → NBA storyTopic = the moment or story. Change the target length to 0:45 or 1:00 (the default is longer than a typical short).
  2. Script, footage, voice, buildIdentical to the NBA mini-doc: hand-off with the fact-check table, collect the missing shots, Preview then Generate voice, Build Premiere XML.
Tip: pick one famous, widely-clipped moment. Fewer segments means far less footage hunting.

6. Real story

A true-story video about real people and events, mostly photos and news footage, with lots of on-screen names, dates and places.

Default length 6:00Source: stills + news clipsOutput: Premiere XML
  1. ＋ New project → Real storyTopic = the story. Set length.
  2. Get the scriptHand-off as before. Claude must give a fact-check table. This is about real people: verify every claim, never state allegations as facts, and drop anything you can't support.
  3. Footage tab → collectMost cards will want a photo or a news clip. Paste a link, or Attach file for images you saved. Stills are saved as images/<segment id>.jpg and get a slow zoom.
  4. Voice, then Build Premiere XMLSame as the NBA mini-doc. Captions (names, dates, places) arrive as on-screen graphics inside the Premiere sequence.
Copyright: using lots of someone else's footage with little commentary can get claims or strikes. Check credits.txt and prefer short clips with real commentary over them.

7. Ranking / top-N

A countdown video: short intro, then from the last place up to #1, then an outro.

Default length 6:00Source: one clip per itemOutput: Premiere XML
  1. ＋ New project → Ranking / top-NTopic = what you're ranking, for example "Top 10 NBA dunkers".
  2. Get the scriptTell Claude how many items and the ranking rule. Each item segment gets a rank (the big number on screen) and a caption (the name). Fact-check table first; verify it.
  3. Footage tab → collect one clip per itemSame as the mini-doc: link plus range, attach a file, or skip.
  4. Voice, then Build Premiere XMLThe number and caption graphics are transparent clips on track V2 in the sequence. They only show up in Premiere, not in an mp4.
Tip: to ask for a longer #1, tell Claude to give the winner two segments.

8. Comic / manga recap

A narrated retelling of a comic, manga or manhwa. A virtual camera zooms, pans and swipes across the panels.

Default length 8:00Source: .cbz, .cbr or .pdfCan finish as a ready mp4
  1. ＋ New project → Comic / manga recapName it after the comic. Pick a style (retell, commentary or mixed) and the reading direction: left to right for western comics and manhwa, right to left for Japanese manga. You can change it later in Settings.
  2. Add the comic fileComic tab → ⬆ Upload comic, or click 📂 Open folder and drag the file into the project's main folder. Accepted: .cbz, .cbr, .pdf, or a .zip of page images. Several files (issues) are joined in name order and pages are numbered continuously.
  3. Run steps → Import comic / mangaUnpacks every page into pages/, and writes the PDF(s) for Claude into comic_review/, 30 pages per PDF. Each page is clean artwork with a "PAGE N" header and a thin ruler grid (0.0 to 1.0) so Claude can read panel positions off it. Claude decides what a panel is.
    .cbr won't open? Rename it to .cbz (many are really zip files), or install 7-Zip and run the step again. A PDF needs the pymupdf package, which SETUP.bat installs.
  4. Check a few shots after the first buildClaude marks each panel as a box (fractions of the page). A box is snapped to the real panel edges when it is close, but if a shot cuts off art, ask Claude to redo that segment's box, or edit the box numbers in the Script tab. Prefer script-found numbered panels? Set "panel_mode": "auto" in config.json under comic, tick Force and import again.
  5. Get the script from ClaudeDo the hand-off above, but attach one PDF per message. Claude replies with segments like {"page":3,"focus":[{"box":[0.05,0.40,0.52,0.71]}],"motion":"push_in","narration":"..."}. For a long comic, send PDF part 2 in the same chat ("continue the ids"), then join the youtube lists into one before importing.
  6. Import the JSONScript tab → paste it → Save. Segments that point at a page or panel that does not exist show as slates, so fix those in the JSON.
  7. Voice tabPick an engine and voice, Save, Preview 3 segments, then Generate. Each picture is cut to the length of its narration, so changing the narration changes the shot length. Only changed segments are re-voiced.
  8. Run steps → Build full videoProduces recap_final.mp4 with the camera moves. This is the slowest step: roughly real time to 2× real time per minute of video on one CPU core, and unchanged clips are skipped on re-runs.
  9. Or edit it yourself (optional)Run Build VideoPad project or Build Premiere XML instead. The camera moves are already baked into each clip in clips/, so keep that folder where it is.
  10. Captions and TikTok (optional)Build subtitles writes recap_subtitles.srt. For shorts, ask Claude for a tiktok section (same page and focus values) and run Build TikTok. The camera re-frames every panel for 9:16 automatically.

What Claude can put in each segment

FieldMeaning
pagePage number from the PDF header.
focus[{"box":[x0,y0,x1,y1]}] one panel or region, as fractions of the page · several boxes = glide across them in order · ["page"] whole page. (Panel numbers like [2] only work in auto mode.)
motionpush_in, pull_out, drift, still, pan_left/right/up/down, shake (impacts). Default auto mixes them.
entercut, fade, pop, slide_left/right/up/down. Default auto: a swipe on a page turn or toward the next panel.
zoom, anchorZoom strength (1.12 default) and where a push-in aims (left, top-right, ...).
Tip: Settings → Render config has the camera defaults for this module: zoom, swipe length, what happens on a new page, and pages per PDF. Lower the pages per PDF if Claude refuses a big file.
Heads-up: like the other modules, the mp4 doesn't burn in captions. They appear in the Premiere XML and the .srt.

Character animation (all modules)

Show a character on screen while you talk: in a corner over movie / show / documentary clips, or centered on a background for solo commentary.

  1. Characters tab → Add PNG(s)Use transparent PNG cut-outs. One file = one picture. Several files = poses (default.png, talk.png = mouth open, angry.png ...). Set "Art faces" so the character is flipped to look toward the middle of the screen.
  2. ScriptGive a segment a Character (the 🧍 box under each segment, or ask Claude: the prompt already explains the fields). Position, pose, animation and entrance are optional.
  3. Solo commentaryTick commentary beat on a segment that has no footage (or set layout to solo): the character appears large in the middle on a gradient, image or video background.
  4. BuildThe talk pose opens and closes with your voice-over (no talk pose: the character bounces with the voice). Consecutive segments with the same character and position keep it on screen without re-entering.
OutputWhere the character is
Premiere XMLOne video track per character (V2, V3, ...); number/caption graphics go on the track after them. Move, scale or delete freely.
VideoPad projectOne video track per character (V2, V3, ...); graphics after them. Original sound and music have their own audio tracks.
Full video (.mp4), VideoPad simple, TikTokBaked into the picture.
Tip: Run steps → Check characters flags PNGs without transparency and writes a preview of every character in both looks. Character layers are large files in char_layers/ (keep them where they are); Characters tab → "Layer file format" can halve their size.

Choosing a voice

Hear a voice before you commit: the sidebar's 🎙 Voice Lab lets you type any text, pick Edge, Kokoro, Chatterbox, Pocket TTS, ElevenLabs or MiniMax and play it right in the browser (no project needed). Inside a project, Voice tab → Preview 3 segments and Hear it here do the same with your own script. ElevenLabs and MiniMax use credits; Kokoro downloads a ~350 MB model once and then works offline.

Chatterbox & Pocket TTS (free local voices)

Two extra voice engines that run on your own PC with no API key and no per-minute cost. Each installs once into its own private folder, so it can never break the rest of Recap Studio.

Speed / pausesPer-segment speed works (pitch is kept). [pause] and [long pause] in the script become real silence. Long narration is split into sentence groups automatically.

Cloning a voice: Voice tab (or Voice Lab) → pick the engine → ⬆ Upload clip, or drop the file into the voices folder and type its name. Use one speaker, no music, no echo, 5-15 seconds. Best format: a 16-bit WAV. Upload clip converts mp3/m4a/flac/ogg to WAV for you; files you drop into voices by hand are converted when you generate (see Clip format). Only clone voices you have the right to use. Chatterbox output carries an inaudible Perth watermark from Resemble AI.

Reference clip format (WAV)

Voice cloning reads a plain 16-bit WAV most reliably. The app converts other formats for you, but if Pocket TTS shows "soundfile is required to read non-WAV or non-16-bit WAV audio files", pick one fix:

  1. Option 1: install soundfile (once)Open a terminal in the Recap Studio folder (click the address bar, type cmd, press Enter) and run venvs\pocket\Scripts\python -m pip install soundfile. Restart START_UI.bat. MP3, FLAC, OGG and M4A clips then work directly. New Pocket installs from SETUP.bat include it already.
  2. Option 2: convert to WAVRun ffmpeg -i myclip.mp3 -ac 1 -ar 24000 -c:a pcm_s16le myclip.wav, put myclip.wav in the voices folder and use that name.

Pocket TTS voice cloning setup (one time)

Pocket TTS's built-in voices work right after install. Cloning needs Kyutai's gated weights, which need a free Hugging Face account and token. Without it you get the error "We could not download the weights for the model with voice cloning".

  1. Accept the termsLog in at huggingface.co, open huggingface.co/kyutai/pocket-tts and click Agree and access repository.
  2. Make a tokenGo to huggingface.co/settings/tokens → New token → type Read. Copy the hf_... text (it is shown only once).
  3. Paste it hereClick 🔑 API keys → Hugging Face token → paste → Save keys. (It is saved in keys.env as HF_TOKEN=.)
  4. Restart the appClose the black window and run START_UI.bat again.
  5. CloneVoice tab → Pocket TTS → upload or type a clip name. The first clone downloads the cloning weights (needs internet once); after that it works offline.
Check it worked: open a terminal in the Recap Studio folder and run venvs\pocket\Scripts\python tts_worker.py --download pocket. It should end with voice cloning: READY. If it says NOT available, the terms in step 1 were accepted on a different Hugging Face account than the token, or the token is wrong.

Tags: to use Turbo's [laugh] etc., set the project's voice style to light or heavy (the PASTE_THIS_TO_CLAUDE prompt already explains the tags to Claude). In plain mode every tag is stripped so nothing is read aloud.

After installing, reload this page so the sidebar shows the engine as installed. The first generation downloads the model; the Voice Lab then loads it again for every preview (10-30 s for Chatterbox), while a full Generate loads it once for the whole video.

Edge-TTSFree, unlimitedNo key needed. Good for testing the whole pipeline. Try Christopher (classic recap narrator) or Guy (documentary).

  • Always press Preview first (3 segments) before spending credits on the full voice-over.
  • Voice text style (Settings tab): plain reads text as written. light/heavy let Claude add emotion tags like [excited], and only ElevenLabs v3 uses them; other engines always get plain text so tags aren't read aloud.
  • A name pronounced wrong? Have Claude respell it for the voice and keep the real spelling in the segment's subtitle field, so captions stay correct.
  • Edit a line and Generate again: only changed segments are re-voiced. Regenerate all redoes everything.

Opening it in VideoPad

  1. Run steps → Build VideoPad project Writes videopad_project.vpj next to the XML, with the same timeline.
  2. File → Open Project and pick it. VideoPad warns that the file "may be damaged" - that is expected, click Try Load (it can appear more than once).
  3. If it will not open run Build VideoPad project (simple) instead: picture + voice only (V1 and A1), no graphics, original sound or music.

Tracks: V1 footage, V2 character (if used), next track number/caption graphics, A1 voice-over, A2 original sound, A3 music. Chapter markers are not carried over (use chapters.txt). Keep clips/, clips_av/, gfx/, char_layers/ and audio_trim/ where they are.

Opening it in Premiere

  1. File → Import premiere_sequence.xml from the project folder. Open the new sequence.
  2. Then import recap_subtitles.srt and drag it onto the timeline (after the sequence is open).
TrackContents
V1Footage, stills, slates (black cards for missing shots)
V2, V3 ...One track per character (only when used); number and caption graphics go on the track after them
A1Voice-over
A2Original clip sound (only segments with keep_audio)
A3Music bed (Settings → "background music bed" on, and a track uploaded to Music)
Don't move or rename the clips/, gfx/, char_layers/ and audio_trim/ folders after importing, or Premiere loses the links. Sequence markers show chapters and any missing shots.

Clips from a different shape (old 4:3 games, vertical video) can look odd: Settings → Fill → pad (black bars) or blur (blurred background).
